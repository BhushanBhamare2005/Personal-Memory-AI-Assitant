## Known Limitations

### Current Constraints
1. Single user only (by design)
2. Synchronous LLM calls
3. No real-time collaboration
4. Limited to ~1000 memories (configurable)
5. No mobile app yet

### Workarounds
- User isolation via user_id parameter
- Can be extended to async
- Can add collaboration layer
- Scale with better indexing
- Can create mobile wrapper
